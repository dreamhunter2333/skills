# Skills

Agent skills collection for Claude Code and other AI coding agents.

## Skills

| Skill | Install | Description |
|-------|---------|-------------|
| [browser-bridge-cli](https://github.com/dreamhunter2333/browser-bridge-cli) | `npx skills add dreamhunter2333/browser-bridge-cli:skill` | Control Chrome/Edge browser via CLI through a browser extension bridge |

## Install

```bash
# Install from standalone repo
npx skills add dreamhunter2333/browser-bridge-cli:skill

# Install to specific agent(s)
npx skills add dreamhunter2333/browser-bridge-cli:skill --agent claude-code codex

# Install globally
npx skills add dreamhunter2333/browser-bridge-cli:skill --agent claude-code -g
```
